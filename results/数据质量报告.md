# HE_2000_2022：日尺度数据检查

本分支仅保存 `HE_2000_2022/` 的原始数据及其 `results/` 检查结果，原始数据版本为 `9acb13732ebc42b2468062b61156c2f26ee2da56`。

已验证九个日尺度矩阵，每个为 8401×288，节点表有 288 个节点。日期表 8395 条，缺少 2000、2004、2008、2012、2016、2020 年的 2 月 29 日；矩阵对应六日均为整行 NaN。原始数据未补值或改写。

请用完整公历日期为矩阵建立索引，或同步删除六个缺失行；不能简单截取前 8395 行。data_quality.csv 中的数值沿用源文件单位，单位与物理变量定义仍需来源确认。

本分支目前保存数据质量核查，尚未针对这套日数据单独完成飓风移动或形成分析。已有小时涡度的形成合成不作为本分支的研究结论。后续可把专属日尺度研究脚本、图表和结果继续放入 results/。

## 复现

Python 3.12，NumPy 2.3.5，pandas 2.2.3；在本分支仓库根目录运行：

```bash
python3 results/audit_daily.py
```

也可设置 CLIMATE_DATA_ROOT 读取另一检出目录；默认读取当前分支中的数据。输出到 results/，不会修改原始数据。
